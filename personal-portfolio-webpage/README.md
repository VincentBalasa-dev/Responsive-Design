# 💼 Vincent's Developer Portfolio

A **modern, responsive web developer portfolio** built with **HTML, CSS, and JavaScript**, designed to showcase my skills, projects, and professional background in a clean and interactive layout.  

This site serves as my **central hub** — linking to all my **freeCodeCamp**, **CodePen**, and **GitHub** projects, while highlighting my technical abilities and design style.

---

## 🎯 Purpose
This project demonstrates how to create a **personal portfolio website** that effectively presents a developer’s profile, skills, and projects with a focus on clarity, responsiveness, and usability.

---

## ⚙️ Features
- 🧭 **Responsive navigation bar** with both top and sidebar menus for mobile users  
- 💬 **About section** detailing background and technical expertise  
- 🧠 **Skills section** with categorized tags for quick visualization  
- 🧱 **Projects gallery** featuring live CodePen previews and links to source code  
- 📬 **Contact section** with Gmail compose link, LinkedIn, GitHub, and CodePen profiles  
- 🎨 **Font Awesome icons** for consistent, modern UI elements  
- 📱 **Responsive design** ensuring smooth viewing across devices  

---

## 🧠 Concepts Demonstrated
- Semantic **HTML5** layout structure (`<nav>`, `<section>`, `<footer>`)  
- **Responsive design principles** with mobile-first CSS styling  
- **Flexbox and grid layouts** for modern UI composition  
- **Navigation toggling** with JavaScript for sidebar interactivity  
- Integration of **Font Awesome** and **external links** for professional presence  
- Accessibility through descriptive alt text and intuitive content hierarchy  

---

## 🧩 Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Styling, grid, and responsive design  
- **JavaScript** – Sidebar menu functionality  
- **Font Awesome** – Icons and visual enhancements  
- **CodePen + GitHub Pages** – Live demos and hosting  

---

## 🚀 How to Run
1. Download or clone this repository.  
2. Open the `index.html` file in your web browser.  
3. (Optional) Host on **GitHub Pages** or any static web host to share your portfolio publicly.

# 📝 Product Landing Page

A **modern, responsive landing page** designed for **Noble Guitars**, showcasing handcrafted premium guitars and their unique features.  
This project was built on **freeCodeCamp** to demonstrate **HTML structure**, **responsive design**, and **form handling** for marketing-oriented product pages.

---

## 🎯 Purpose
This project demonstrates how to create a professional product landing page that presents product features, visual media, and pricing options with a consistent and engaging layout.

---

## ⚙️ Features
- **Responsive header** with company logo and navigation links  
- **Hero section** with call-to-action email subscription form  
- **Features section** highlighting sustainability, engineering, and warranty  
- Embedded **YouTube video** demonstrating craftsmanship  
- **Pricing section** displaying three product tiers with descriptions and buttons  
- **Footer section** containing social media links and legal info  
- Font Awesome icons integrated for clean and modern visuals  

---

## 🧠 Concepts Demonstrated
- Semantic HTML5 layout using `<header>`, `<nav>`, `<section>`, and `<footer>`  
- Anchor links for smooth internal navigation  
- Form handling with `action` for email submission  
- Responsive layout and typography using CSS  
- Icon integration using **Font Awesome**  
- Accessibility through descriptive image alt text and clear structure  

---

## 🧩 Tech Stack
- **HTML5** for structure  
- **CSS3** for responsive styling  
- **Font Awesome** for icons  
- **JavaScript (optional)** for future enhancements  
- **YouTube Embed** for product video integration  

---

## 🚀 How to Run
Open the **`index.html`** file in your browser to view the landing page.  
You can also host it on **GitHub Pages**, **CodePen**, or any web server for public viewing.

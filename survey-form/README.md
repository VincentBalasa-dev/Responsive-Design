# 📝 Event Registration Form

A clean and responsive **HTML5** and **CSS3** form designed for event sign-ups.  
This project was built on **freeCodeCamp** to practice **form validation**, **semantic HTML**, and **accessible user interface design**.

---

## 🎯 Purpose
This project demonstrates how to create a fully functional registration form with **input validation**, **dropdown menus**, **radio buttons**, and **checkbox selections**.  
Users can fill out their personal information, select event preferences, and submit their registration seamlessly.

---

## ⚙️ Features
- Input fields for **Name**, **Email**, and **Age** with built-in validation  
- **Dropdown menu** for selecting event types  
- **Radio buttons** for choosing a preferred session time  
- **Checkboxes** for multiple topics of interest  
- **Textarea** for additional comments or requirements  
- Responsive layout ensuring proper display across devices  
- Semantic and accessible structure following best practices

---

## 🧠 Concepts Demonstrated
- Semantic HTML5 structure (`<form>`, `<fieldset>`, `<legend>`, `<label>`)  
- Input validation using HTML attributes (`required`, `min`, `max`, `type`)  
- Use of radio buttons and checkboxes for grouped selections  
- Dropdown selection (`<select>` and `<option>`) for categorized inputs  
- User experience design through clear labeling and spacing  
- Accessibility practices (proper use of `for` and `id` attributes)

---

## 🧩 Tech Stack
- **HTML5** for content structure  
- **CSS3** for styling (if applicable)  
- **Vanilla JavaScript** (optional, for validation or interactivity)

---

## 🚀 How to Run
Open the **`index.html`** file in your browser to view and interact with the form.  
You can also host it online (e.g., GitHub Pages, CodePen, or Netlify) for easy access.

# 📝 Tribute Page – Dr. Norman Borlaug

A simple and responsive **HTML5** tribute page dedicated to **Dr. Norman Borlaug**, known as the *Father of the Green Revolution*.  
This project was built on **freeCodeCamp** to practice **semantic HTML**, **accessible image captions**, and **page layout structure**.

---

## 🎯 Purpose
This project demonstrates how to create a clean, informative tribute page that honors a notable figure, featuring an image with caption, biographical timeline, and external references for further reading.

---

## ⚙️ Features
- Prominent **title and main section** introducing Dr. Norman Borlaug  
- **Centered image** with descriptive alt text and caption  
- Section for **biographical timeline** using a list  
- External link to **Wikipedia** for extended information  
- Semantic structure following accessibility standards  
- Fully responsive layout using simple CSS styling  

---

## 🧠 Concepts Demonstrated
- Semantic HTML5 structure (`<main>`, `<section>`, `<h1>`, `<ul>`, `<a>`)  
- Use of **alt text** for image accessibility  
- Proper **caption placement** and **link targets** (`target="_blank"`)  
- Organized page hierarchy using headings and lists  
- Clean and minimal web layout  

---

## 🧩 Tech Stack
- **HTML5** for content structure  
- **CSS3** for layout and styling
